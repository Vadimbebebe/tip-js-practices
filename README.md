## Задание 1

Файл `hello.js` запущен двумя способами.

**В Node.js:**
```
Студент: Иванов Иван
Группа: ПИ-21
Практическая работа: 1
JavaScript успешно запущен
Тип document: undefined
```

**В браузере (Console):**
```
Студент: Иванов Иван
Группа: ПИ-21
Практическая работа: 1
JavaScript успешно запущен
Тип document: object
```

**Различие:** Node.js — серверная среда выполнения, в ней нет DOM и объекта `document`. Браузер предоставляет `document`, поэтому `typeof document` даёт `object`. Один и тот же файл запускается в обеих средах, но обращение к браузерным API в Node.js недоступно.

## Задание 5. Отладка

**Исходный вывод (до исправления):**
```
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

| Ошибка | Что наблюдалось | Причина | Исправление | Результат после исправления |
|---|---|---|---|---|
| Обработка количества задач | `completedTotal = "32"` вместо 5 | Строки складывались как текст: `"3" + "2"` = `"32"` | Обернул операнды в `Number(...)` | Выполнено: 5, Осталось: 3 |
| Граница цикла | `controlSum = 6` вместо 10 | Условие `taskNumber < 4` не включало 4 | Заменил на `taskNumber <= 4` | Контрольная сумма: 10 |

**Вывод после исправления:**
```
Выполнено: 5

Контрольная сумма: 10
```
